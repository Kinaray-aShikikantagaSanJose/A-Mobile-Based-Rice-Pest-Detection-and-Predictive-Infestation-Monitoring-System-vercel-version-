# Example photos for the "What to look for" guide

Put one photo per entry here, named after its key, as `.jpg` or `.png`.
The apps show a placeholder for any entry without a photo. No restart needed.

Pests: `brown_planthopper`, `green_leafhopper`, `rice_bug`, `rice_stem_borer`

Symptoms: `hopperburn`, `honeydew_sooty_mold`, `wilting_lodging`,
`tungro_discoloration`, `stunted_plants`, `reduced_tillering`, `empty_grains`,
`grain_spots`, `rice_bug_odor`, `deadhearts`, `whiteheads`, `bore_holes_frass`

Example: `guide_photos/deadhearts.jpg`. Use your own field photos or ones you
have permission to use (e.g. from PhilRice or IRRI Rice Knowledge Bank, with
credit). Keep them under about 500 KB so phones download them quickly.
